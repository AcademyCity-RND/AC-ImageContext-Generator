# Workspace Template

Gunakan folder ini sebagai *placeholder* untuk struktur kerja Anda.
1. Salin folder `MATKUL_CONTOH` dan ganti namanya sesuai kode mata kuliah Anda (misal: `KEPL`, `PPG`).
2. Masukkan screenshot ke dalam folder `screenshots/`.
3. Masukkan materi/referensi ke `_reference/`.
4. Hasil `inisiasi.txt` akan muncul di `inisiasi/`.

Direktori ini sudah di-ignore oleh Git agar data pribadi Anda tetap aman.
